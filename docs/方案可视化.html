5. 多端演进对比与结论

端优先级技术路线结论
Web PC 浏览器P0 首发Vue3+Vite，前后端分离 JSON API核心编辑流程大屏效率最高，成本最低，作品集演示首选
H5 移动网页P1同套前端响应式；移动端只做查看/对话/浏览草稿不另起炉灶，靠响应式+精简布局控制成本
桌面端P2优先 Electron（复用 Node 逻辑）；轻量需求再评估 Tauri（需少量 Rust）待 Web 稳定、确有离线诉求再做，不先上框架
小程序P2 后置uni-app 可一套到小程序+H5文件与模型调用受审核/备案限制，体验不适合重型编辑，后置
架构上所有能力走统一 JSON API，新增端只是换壳，业务逻辑不重写。
