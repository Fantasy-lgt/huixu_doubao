分支与失败回退
材料不足 / 未勾选（F1-2）
主按钮禁用；列出缺口月份与类型建议，可跳转材料库新建或切手动表单。
AI 大纲失败（F1-3）
401/429/超时/坏 JSON → 自动回退本地规则稿，保留已圈选材料，不污染原稿、不自动重试收费调用。
无适配模板（F1-5）
返回最接近近似卡说明差异；可把当前大纲存为元数据卡（仅标题/标签/结构）。

材料被改删 → confirmedVersion 清空待重核；导出异常 → 保留版本可重试，不重复请求模型。
终点：下载可编辑 PPTX（带出处角标）+ 草稿回到工作台草稿列表；两个账号数据互不可见。

分支与失败回退
缺月 / 无材料（F2-1）
缺月斜纹格显式标注待补；无材料进入空态，引导先入库，不主观推断补全。
候选未确认（F2-2）
AI 建议条目默认不入库；来源材料缺失的候选标待补，确认后才计入正式清单。
LLM 连贯化失败（F2-3）
退化为确定性名单 + 时间线纯文本，不阻塞清单产出，不编造实体信息。
清单导出失败（F2-4）
保留页面聚合结果，可重试；不重复发起 LLM 请求。
终点：年度清单含每条来源引用；跨月同一事项不重复计为新增成果；不输出绩效结论类主观判断。

连通测试结果分类（F3-3）与保护规则
401 / 403 鉴权失败
红提示 Key 无效或无权限，不保存入库，引导重新粘贴。
429 限流 / 超时不可达
黄提示稍后重试或检查服务器出网策略；保持本地规则模式，不反复自动请求。
坏 JSON / 协议不符 / 5xx
提示格式不符或服务暂不可用；错误记录不含 Key 明文。
移除 Key / 全程无 Key
立即切本地规则模式，历史草稿与材料保留；备份导出剔除密钥字段，不进日志。
终点：AI 可用（外发前单独确认）或保持本地规则模式；主闭环 F1 在两种模式下都能完成。
跨流共用保护规则（前端骨架务必落地）
场景前端表现系统保护 / 回退
未登录 / 会话过期 401提示后跳 /login?redirect=清前端态，不写半成品
越权访问他人资源404 不存在或无权访问服务端记安全日志，不暴露存在性
AI 鉴权 / 限流 / 超时 / 坏结果对应色提示 + 本地结果兜底保留原稿，整份拒绝坏输出，不自动重试收费调用
导出 / 生成异常提示原因，草稿版本保留可重试；外发范围始终为本次材料子集
无 API Key界面标识「本地规则模式」规则整理链路完整可用，不阻塞月度闭环
