# PRD-02 材料库（MVP 开发版）

版本：v1.0 ｜ 所属阶段：W2（阶段 B）｜ 前置依赖：PRD-01 账号与隔离完成
关联文档：产品方案 5.2、6.3 节；初代 v0.1 材料逻辑（domain.cjs 本地整理规则可移植）

---

## 1. 目标与范围

### 1.1 目标
把用户的工作材料按「标题 + 类型 + 标签 + 期间 + 场合 + 原文」结构化沉淀，支持组合筛选与全文关键词检索；每条材料是后续汇报初稿和年度汇总的事实来源，**原文只保留不改写**。

### 1.2 本期做
- 材料列表、详情查看、新建（粘贴正文 / 上传 TXT、Markdown）、编辑、删除。
- 材料类型枚举 + 自定义标签；期间（月份）与汇报场合字段。
- 组合筛选：类型、标签、月份、关键词搜索。
- 去重校验；删除材料时使引用它的草稿失效（沿用初代规则并适配多用户）。
- 材料与草稿的来源对照关系（为 PRD-03 编辑器预留）。

### 1.3 本期不做
- Word（.docx）、PDF、PPTX 原文件解析（P1；本期上传入口明确提示支持格式）。
- 材料 OCR、图片内容识别。
- 材料版本历史对比（本期只保留最新版 + 更新时间）。
- 材料收藏置顶、分享链接、多人可见。
- 文件夹/层级目录（扁平列表 + 筛选满足本期需求）。

## 2. 数据模型：materials 表

| 字段 | 类型建议 | 约束/规则 | 说明 |
| --- | --- | --- | --- |
| id | uuid | PK | |
| user_id | uuid | FK→users，非空，索引 | 归属隔离 |
| title | varchar(100) | 非空，去首尾空格 | 材料标题，最长 100 字 |
| material_type | varchar(20) | 非空，取值见枚举 | 材料类型 |
| tags | jsonb/text[] | 默认 `[]`，标签总数 ≤ 8 个，单个 ≤ 12 字 | 自定义标签 |
| period | varchar(7) | 可空，格式 `YYYY-MM`；允许「未标记期间」 | 归属月份；空值不等于 12 月 |
| occasion | varchar(30) | 可空，取值见场合枚举 | 替代初代「部门」字段：汇报场合 |
| body | text | 非空，单份 ≤ 20000 字（沿用初代上限，服务端校验） | 原文只读保留，系统不改写 |
| source_name | varchar(180) | 默认「手工录入」 | 来源文件名/出处名 |
| file_ref | varchar(255) | 可空 | 本期无文件落库时留空；上传 TXT/MD 内容直接入 body |
| version | int | 默认 1，每次编辑 +1 | 供草稿引用校验 |
| created_at / updated_at | timestamptz | 非空 | |
| is_sample | bool | 默认 false | 虚构示例标记，正式版可不提供示例加载 |

### 2.1 material_type 枚举（材料类型）

| 值 | 中文展示 | 典型内容 |
| --- | --- | --- |
| work_report | 工作汇报 | 月报、周报、管理会汇报材料 |
| project_progress | 项目进展 | 技改项目、客户项目推进情况 |
| meeting_minutes | 会议纪要 | 例会、专题会记录 |
| hr_admin | 人事行政 | 人员变动、考勤、行政事务 |
| customer_business | 客户往来 | 客户走访、合作洽谈、协议进展 |
| contract_deal | 合同商务 | 合同、报价、招投标材料 |
| regulation | 制度通知 | 上级文件、制度、通知要求 |
| other | 其他 | 无法归类，必须给标题和正文 |

### 2.2 occasion 枚举（汇报场合，可空）

月度管理会 / 部门例会 / 项目复盘 / 年度总结 / 述职竞聘 / 专项汇报 / 其他。用户也可不选。

### 2.3 去重规则
同一 `user_id` 下，若 `period + body 正文指纹（去空白后哈希）` 与已有材料相同 → 提示「内容与已有材料重复」，409 拒绝写入；标题不同不视为重复。

## 3. 功能需求

### FR-M01 材料列表页
- 布局：顶部筛选区（类型下拉/标签筛选/月份选择/关键词搜索框）；下方材料卡片列表；右上角「新建材料」主按钮。
- 卡片信息：类型色标 + 标题、期间（未标记显示「未标期间」）、场合标签、前 2–3 行正文预览、来源名、更新时间、字数；操作入口：查看、编辑、删除。
- 排序：默认按 updated_at 倒序；搜索/筛选后结果即时刷新；空结果显示空状态文案与新建入口。
- 统计条（可选轻量）：当前筛选下材料份数、覆盖月份数；不做复杂图表。

### FR-M02 新建材料（弹窗或独立表单页，建议弹窗减少跳转）
- 字段：标题（必填）、类型（必选，默认「工作汇报」）、标签（多选输入，可新建标签）、期间（月份选择，可空）、场合（下拉，可空）、来源名（可空，默认手工录入）、正文（多行文本，必填，实时字数显示 x/20000）。
- 两种录入方式：
  1. 直接粘贴：正文框粘贴文本。
  2. 上传文件：仅接受 `.txt` / `.md` / `.markdown`（UTF-8）；读取内容填入正文框供用户确认后保存；单文件 ≤ 20000 字，超出提示删减或拆分，不静默截断。
- 保存前服务端校验全部规则；保存成功返回列表并定位到新卡片；表单已填内容在校验失败时保留。

### FR-M03 查看材料
- 只读详情：完整正文、元信息、来源、创建/更新时间；支持跳转「用这份材料生成汇报」（衔接草稿功能，本期可先留按钮置灰或跳转到工作台并预选该材料）。

### FR-M04 编辑材料
- 可改全部字段；正文编辑后 `version+1`；服务端重新走去重与长度校验；保存成功更新 updated_at。
- **引用失效规则（关键，沿用初代）**：任何草稿若引用了本材料，且本次修改使 `version` 变化 → 对应草稿 `confirmedVersion` 清空、标记「依据已更新待重新核对」；删除材料同理，使引用草稿失效。前端在编辑保存后给出提示：「有 N 份草稿引用了这份材料，将需要重新核对」。

### FR-M05 删除材料
- 二次确认弹窗，说明三点影响：原文删除不可恢复；引用它的草稿将失效；已导出的 pptx 文件不会被删除。
- 确认后服务端删除记录并批量失效相关草稿；取消则无任何变化。
- 不做批量删除（本期）。

### FR-M06 搜索与筛选组合
- 关键词：匹配标题 + 正文 + 来源名（PG `ILIKE`/全文检索均可，本期数据量小用模糊匹配即可，不引外部检索引擎）。
- 组合条件取交集；筛选条件可单独清空；URL 可记录筛选参数便于分享当前视图（可选）。

## 4. 页面交互要点

- 筛选区一行内排布：类型、月份、关键词；标签用下拉多选或标签 chips 展开区。
- 新建表单内「上传文件」按钮旁注明支持格式；不支持格式点击即给提示，不发起解析。
- 正文区保留用户原始换行与分段；系统展示时按原文换行显示，不自动改写措辞。
- 窄屏（手机浏览器）筛选区折叠为一行下拉，卡片单列堆叠。

## 5. 接口定义

| 接口 | 方法 | 入参 | 行为 / 主要错误 |
| --- | --- | --- | --- |
| `/materials` | GET | query: type, tag, period, keyword, page(可选) | 返回当前用户材料列表（分页可选；本期材料量小可一次返回并前端过滤）；未登录 401 |
| `/materials` | POST | title, materialType, tags, period?, occasion?, body, sourceName? | 校验后创建；参数错 400；重复 409 `MATERIAL_DUPLICATE`；超长 413/422 |
| `/materials/:id` | GET | — | 详情；不归属 404 |
| `/materials/:id` | PUT | 同上可改字段 | 更新、version+1、失效关联草稿；不归属 404 |
| `/materials/:id` | DELETE | — | 先确认影响；删除并失效草稿；不归属 404 |
| `/materials/tags` | GET | — | 返回当前用户已有标签集合，供选择器自动补全（可选） |

所有接口由鉴权中间件包裹；服务端强制 `user_id` 作用域；响应错误统一 `{error:{code,message}}`。

## 6. 校验规则汇总（服务端为最终权威）

| 规则 | 标准 |
| --- | --- |
| 标题 | 非空、去首尾空格、≤100 字 |
| 类型 | 必须命中 2.1 枚举 |
| 标签 | ≤8 个，每个 ≤12 字，去除空标签与重复标签 |
| 期间 | 空 或 `YYYY-MM`（2000–2100）；非法月份拒绝 |
| 正文 | 非空、≤20000 字；剔除控制字符（保留换行/制表符） |
| 来源名 | ≤180 字，空则默认「手工录入」 |
| 文件 | 仅 txt/md/markdown；MIME 与扩展名校验；UTF-8 读取，解码失败提示换格式 |
| 去重 | 同用户下 period + 规范化正文哈希重复 → 409 |

## 7. 验收用例

### 成功场景
| 编号 | 步骤 | 预期 |
| --- | --- | --- |
| M-OK1 | 新建材料：选类型、打 2 个标签、填月份、粘贴正文保存 | 列表出现新卡片，元信息正确，字数统计正确 |
| M-OK2 | 上传一份 md 文件保存 | 正文完整填入，分段保留，来源名为文件名 |
| M-OK3 | 按类型 + 月份 + 关键词组合筛选 | 仅显示同时满足条件的材料；清空条件恢复全量 |
| M-OK4 | 编辑材料正文并保存 | version+1；关联草稿被标记待重新核对；时间戳更新 |
| M-OK5 | 两份不同用户登录互看材料库 | 互相不可见（与 PRD-01 联调验证） |

### 失败与边界
| 编号 | 操作 | 预期 |
| --- | --- | --- |
| M-F1 | 标题空 / 正文空 / 超 20000 字 | 400/422 明确提示，表单内容保留 |
| M-F2 | 上传 docx/pdf | 入口拒绝并提示本期支持格式，不上传不解析 |
| M-F3 | 同用户重复粘贴相同内容 | 409 提示重复，不写入 |
| M-F4 | 删除被草稿引用的材料 | 确认后删除，关联草稿失效提示出现；取消删除无变化 |
| M-F5 | 越权访问他人材料 ID（读/改/删） | 全部 404，无数据泄露 |
| M-F6 | 非法月份（如 2026-13）、非法类型值 | 400 拒绝 |
| M-F7 | 无结果搜索 | 显示「没有匹配材料」空状态 + 新建入口，不报错白屏 |

### 自动化测试要求
- 创建/更新/删除接口校验与归属隔离测试；去重测试；长度与枚举非法值测试。
- 草稿失效联动：建草稿引用材料 → 更新/删除材料 → 断言草稿确认状态被清空。

## 8. 与其他模块的衔接

- **汇报工作台（PRD-03）**：按用户选择的类型/期间/场合筛选材料集合作为初稿输入；每条初稿条目可回溯到具体材料与原文摘录。
- **年度回顾**：按 period 聚合材料；缺月判断基于材料记录，不按材料内容主观推断。
- **实体表（PRD-05）**：实体候选建议从材料正文抽取，来源指向材料 id；人工确认后入库。
- **AI 生成（PRD-04）**：外发范围 = 用户本次选中的材料子集，不是全库；外发前展示份数与标题清单供确认。

## 9. 待定项
