# 汇序 · 管理会汇报工作台 — UI 风格设定与设计规范 v1

> 用途：把 8 页低保真线框升级为高保真控制台（web-console，1440×900 主取景、兼容 1920 宽屏、390 窄屏折叠）的唯一数值依据。
> 前端实现时所有颜色、字号、圆角、间距从本文 token 取，不再临场凭感觉填。术语后面括号里是一句大白话解释。

---

## 0. 一句话设计主张

**亲和轻盈的紫蓝工作台，规整而不沉闷**：长时间盯屏不刺眼、信息先于装饰、每个操作都有位置和反馈；主色对齐参考应用 Upsello 的紫蓝 `#6C5CE7`，全站只保留一个实心主色，避开荧光紫和框架默认蓝，先传达"AI 助手、友好可信"，密度和表格结构仍按 B 端后台标准执行。

判断一页好不好看，先记住三条 B 端和官网相反的标准：

1. 控制台满屏是大图就是设计错误，屏幕要给数据、筛选和操作入口；
2. 主指标要比次指标大一档，不做四张等大的卡片；
3. 表格靠行高和 1px 细线出密度，不靠重阴影和斑马纹。

## 1. 风格签名（六维定调，已写入 style.json）

| 维度 | 选定值 | 为什么是它（结合本产品） |
|---|---|---|
| ground 底色 | **light 亮场** | 行政内勤白天长时间写稿、翻材料，亮场低刺眼；暗色是夜间数据监控的选择，不适合写作工具 |
| typeVoice 字的性格 | **sans-cool 无衬线冷静体** | 后台/工具/表格类，中文黑体 + 系统无衬线，先保证小字可读，不要衬线文艺感 |
| imageWorld 影像世界 | **abstract-graphic 图形抽象，无摄影主视觉** | 主角是表格、任务状态和文字，不是照片；图表用内联 SVG 画，图标用矢量图标，不用生图照片充数 |
| layoutLogic 版面逻辑 | **grid 网格** | 左导航 + 主区栅格，材料/草稿/模板都是列表档案，天然分格排列 |
| colorStrategy 配色分工 | **tri-role 三色分工** | 品牌紫蓝（身份）+ 语义色（完成/异常/预警）分工，多状态一眼分清；语义色与主紫错开，不能互相冒充 |
| motionVoice 动效语气 | **static 静态为主** | 只做 hover/focus/切换/骨架屏反馈，不做视差滚动和入场大动画；工具稿动效服务状态，不服务奇观 |

**一句拒绝清单（内部方法，不进对客文档）**：不用深色赛博底、不用紫蓝渐变铺满整页、不用大圆角胶囊铺满版面、不用四宫格等大卡、不用 emoji 当功能图标、不用满屏彩色图表、不做滚动视差、不用荧光紫。

## 2. 配色（写 CSS 前先锁死这张表）

### 2.1 设计推导（不用行业刻板印象，每个色说出来源）

| 角色 | 色值 | 来源解释 |
|---|---|---|
| 页面底 `--page` | `#F4F3FB` | 淡紫白纸：对齐 Upsello 白到淡紫的亮场，不是纯白、不是中性灰 |
| 卡片/面板 `--bg` | `#FFFFFF` | 浮在淡紫底之上的白壳，是构图元素不是页面底色 |
| 内嵌块 `--panel-2` | `#F0EEF9` | 表头、输入框、图标底、选中 chip 的浅紫灰底 |
| 发丝线 `--border` | `rgba(54,44,104,.08)` | 1px 紫相低透明线，绝不用硬 `#CCC/#333` |
| 品牌主色 `--accent` | `#6C5CE7`（紫蓝 Violet-Indigo） | 取色自 Upsello 实心按钮与用户气泡；比荧光紫沉稳、比科技蓝柔和，承担"AI 助手感" |
| 辅助紫 `--accent-2` | `#8B7CF6` | 品牌标渐变亮色、第二序列提示，只在 logo 渐变与 hover 辅助处出现，面积小 |
| 浅染 `--accent-soft` | `rgba(108,92,231,.10)` | 当前导航、选中行、focus 环、chip 选中底、问候横幅底 |
| 主色上的字 `--on-accent` | `#FFFFFF` | 主按钮与用户气泡填充上的文字 |
| 主色光晕 `--glow` | `rgba(108,92,231,.28)` | 每屏最多一次，只给主 CTA 或关键卡 |

### 2.2 墨色三级（B 端可读性的关键，弱字不能再浅一档）

| token | 色值 | 用途 | 对比度要求 |
|---|---|---|---|
| `--ink-1` | `#1F1B3D` | 页面标题、KPI 大数字、表头条目（深紫墨） | — |
| `--ink-2` | `#403C5E` | 正文、表格单元格 | 对 `--bg` ≥4.5:1 |
| `--ink-3` | `#6E6B8C` | 标签、caption、时间、表头（冷紫灰） | 对 `--bg` ≥4.5:1，不能直接套纯灰 |

### 2.3 语义功能色（和品牌色严格分开，别混用）

> 最常见的后台 bug：品牌色和"成功/异常"用了同一个绿或红，用户分不清"这是品牌强调还是数据异常"。

| token | 浅底色 | 深色字 | 用途 |
|---|---|---|---|
| `--up` 完成/已校验 | `rgba(46,158,119,.12)` | `#1F7A59` | 已确认草稿、材料校验通过（中性绿，与主紫错开） |
| `--down` 异常/冲突 | `rgba(208,72,72,.11)` | `#A83232` | 缺来源、版本冲突、导出失败 |
| `--warn` 待办/预警 | `rgba(183,121,31,.14)` | `#85590F` | 缺月份标签、待补充、Key 未配置 |

规则：状态标签永远"浅底 + 深字"两个值配对；只用一个纯色值必然掉到 3:1 以下，看得见但读不清。

### 2.4 明确禁用的颜色

- 框架默认色整组禁用：Tailwind 蓝 `#3B82F6/#2563EB`、荧光紫 `#A855F7/#C084FC/#8B5CF6`、高饱和绿 `#22C55E`、红 `#EF4444`、橙 `#F97316`、中性灰 `#6B7280/#9CA3AF`；Material `#2196F3/#4CAF50`；Bootstrap `#007BFF/#28A745`；所有 HTML 具名色。本套主紫 `#6C5CE7` 是唯一允许的紫色，其余紫调只能作它的浅染。
- 页面主底禁用 `#FFFFFF / #000000 / #F9FAFB / #111827 / #1F2937`；禁止紫蓝渐变铺满整页（参考图的渐变只用于营销稿氛围，控制台保持淡紫白纸平涂）。
- 全页彩色不超过 1 个身份紫 + 3 个功能色，其余靠墨色三档明度区分。

## 3. 字体与字阶

### 3.1 字体栈（离线可用，不走外网 CDN）

```css
--font-body: "PingFang SC", "Microsoft YaHei", "Segoe UI", system-ui, -apple-system, sans-serif;
```

工具型控制台声明单字体族（`single-family` 豁免）：靠**字号、字重、颜色**拉开层级，不强行凑两种字体；所有数字加 `font-variant-numeric: tabular-nums`（等宽数字，否则表格列宽来回跳）。

### 3.2 字阶表（B 端真实取值，不是官网巨字逻辑）

| 角色 | 字号/字重 | 用途 | 相对正文 |
|---|---|---|---|
| KPI 主数字 | 28px / 700 | 本月成稿数（主指标大一档） | 2.0× |
| KPI 次数字 | 22px / 700 | 材料数、草稿数、待校验条数 | 1.6× |
| 页面标题 h1 | 17px / 650 | 顶栏当前页名 | 1.25× |
| 区块标题 h2 | 15px / 600 | 面板标题、任务卡标题 | 1.1× |
| 正文 body | 13.5–14px / 400 | 表格、列表、说明文字 | 1.0（基准） |
| 辅助 caption | 12px / 400，字距 +0.02em | 时间、单位、表头、标签 | 0.87× |

相邻层级 ≥1.45× 的断崖只用于 KPI 主数字；工具稿内部标题不搞巨字。中文正文 ≥13.5px，禁止小于 12px 的可读正文。

## 4. 圆角（角色分工，禁止全站一个值）

| 角色 | 数值 | 用在哪 |
|---|---|---|
| shell 大容器 | `14px` | 主面板、抽屉外壳、弹窗 |
| card 卡片 | `12px` | KPI 卡、任务卡、材料卡 |
| control 控件 | `8px` | 输入框、下拉、按钮（次按钮）、小标签底 |
| pill 胶囊 | `999px` | 筛选 chip、状态 tag、头像、Toast |

shell 与 card 差 2px 形成层级；圆角较上一版上调，对齐 Upsello 的圆润亲和感；**全站不用 50px 大胶囊铺满版面**，只有可点的筛选/标签/Toast 用胶囊，卡片与容器保持中小圆角。

## 5. 间距、栅格与尺寸

- 基距 `4px`；常用步长 4 / 8 / 12 / 16 / 24，不硬凑 8 的倍数。
- 卡片内 padding：12–16px；区块之间 gap 16px；主区左右 padding 24px。
- 左侧导航宽 `220px`（≤1180px 时收成 64px 纯图标栏）。
- 表格行高 `42px`（密度第一决定项）；表头 38px；单元格左右 padding 16px。
- 1440 取景：主区内容自然铺满；1920 宽屏：内容最大宽度不强行拉伸到满，面板保持舒适密度；390 窄屏：导航折为顶部横向图标条，三栏编辑器折单列，栅格全部 1fr。
- 栅格：KPI 区 `repeat(4,1fr)`，主副面板 `2fr 1fr`，材料卡网格 `repeat(auto-fill,minmax(280px,1fr))`。

## 6. 阴影与层级

浅色页用三层弱有色阴影（紫相，不用单层纯黑影），全套配方只两套：

```css
/* 卡片：接触影 + 形体影 */
--shadow-card:
  0 1px 2px rgba(54,44,104,.05),
  0 8px 20px -8px rgba(54,44,104,.12);
/* 浮层：弹窗/抽屉 */
--shadow-overlay:
  0 2px 6px rgba(54,44,104,.06),
  0 24px 60px -20px rgba(54,44,104,.24);
```

规则：`blur ≥ 2× y-offset`；列表和表格优先用 1px 发丝线分界，不靠阴影堆叠；禁止 `box-shadow:0 2px 8px rgba(0,0,0,.1)` 这类纯黑单层影。

## 7. 图标规范

- 统一用内置 Phosphor 图标（MIT，`viewBox="0 0 256 256"`、`fill="currentColor"`），**一稿只用 regular 一种字重**；颜色吃 `--ink-3`，选中态吃 `--accent`。
- 导航与操作位共 15 枚左右：工作台 grid-nine、材料库 folder-open、草稿 pencil-simple、助手 chat/sparkle、模板库 layout、年度回顾 calendar-blank、设置 gear、搜索 magnifying-glass、新建 plus、导入 upload-simple、导出 export、时间 clock、用户 user-circle、校验 shield-check、提示 info/warning。
- **禁止 emoji 当图标或材料位**；禁止 24×24 `fill=none` 的通用描边图标（Feather/Lucide 默认造型等同框架蓝一样属于没做设计决定）。
- 后台高密界面在 HTML 头部声明 `<!-- design-intent: system-icons -->` 说明使用系统级矢量图标。

## 9. 8 页结构如何落到一个控制台骨架

飞书式外壳：**左侧导航 + 中间主区 + 右侧上下文栏（可折叠）**。导航切换视图，不做整页跳转。

| 线框页 | 控制台里的落点 |
|---|---|
| 1 登录注册 | 左右分栏登录屏（固定覆盖层、无侧栏；≤960px 降单列并隐藏宣传区）：左侧紫渐变产品宣传区（品牌行 + 主张标题 + 三条卖点图标说明 + 纯 CSS 产品示意 mock），右侧表单列（随模式切换的欢迎语 + 登录/注册 tab + 工作邮箱/密码/注册确认密码）；校验为三级反馈——汇总错误条 + 出错字段红边浅红底 + 字段级红字提示，确认密码失配即时提示、输入即清错；通过后进主壳，侧栏底部「退出登录」返回登录屏 |
| 2 工作台 | 默认主视图：问候条 + 两张任务卡 + 指令输入框与建议 chips + 最近草稿表；右侧待办提示/本月统计 |
| 3 材料库 | 独立视图：4 张统计卡 + tab（全部材料/最近引用/回收站）+ 类型 chips + 月份下拉 + 搜索框 + 8 行材料表（类型/期间/校验状态/引用次数/时间/操作）+ 分页器 |
| 4 三栏编辑器 | 顶部五步步骤条（准备材料→大纲确认→逐页核对→模板匹配→导出），步骤可点切换、上一步可回退；五个独立面板：①左范围筛选 chips + 右候选材料勾选（≥1 才可下一步）；②左三章节节点 + 右大纲页 P1–P5，可增删排序；③原三栏（左依据材料 / 中三章节条目：已校验绿、待补充琥珀、草稿待确认 / 右大纲页属性）；④匹配 banner + Top3 模板卡（Top1 紫边「用于本稿」，可替换备选）；⑤左导出设置/页面清单 + 右导出前检查清单（绿通过 / 黄阻塞，失败不丢稿提示）。底部操作栏随步骤切换主按钮文案，阻塞项存在时禁用下一步/导出；导出 PPTX 为服务端 pptxgenjs 占位（W3 落地） |
| 5 助手抽屉 | 全局右侧抽屉，任何视图可呼出，不离开当前页 |
| 6 模板库 | tab + Top1 匹配提示条 + 场景 chips + 6 张模板卡（首张紫边高亮 Top1，含匹配度分数与大纲 mini 清单，卡片等高、操作基线对齐） |
| 7 年度回顾+实体表 | 左 12 月覆盖热力格（紫深浅四档 + 图例）+ 右年度统计；下方实体表 chips（人员/客户/合同项目），已确认绿点、AI 候选琥珀待人工确认入库 |
| 8 设置/Key | 四组两列：模型与生成（Key 掩码 + 连通测试 + 本地规则模式）、数据与备份（用量条 38% + 导入导出）、账号与偏好、隐私与付费预留（会员位灰显 disabled，本期不接支付） |

**完成度口径**：登录屏（P1）+ 六个视图（工作台 / 材料库 / 三栏编辑器 / 模板库 / 年度回顾 / 设置）均为高保真静态原型。登录屏做前端校验（邮箱格式、密码 ≥6 位、注册两次密码一致）与按钮加载态，反馈分汇总错误条、出错字段红边浅红底、字段级红字提示三级，确认密码输入时即时比对、失配即提示，输入过程自动清除对应字段错误；校验通过后进入主壳；左侧导航经 `goView` 真实切换并同步面包屑、页面标题与顶栏控件显隐；助手为全局右侧抽屉；编辑器五步由 `renderStep(n)` 统一切换 done/cur 状态、面板显隐、提示文案与主按钮文案，上一步回退、下一步推进、第五步为导出占位 toast，capture 状态扩至 19 态（含 ed-step1/2/4/5）。配套设计输入另见根目录《IA站点地图-路由与数据对照表.md》《IA站点地图.html》《核心任务流说明.md》《核心任务线wireflow.html》与《技术Spike方案与脚本模板.md》，低保真线框 P4 内同步含五步分屏 mini-frame。交互深度以登录/注册切换、视图切换、筛选 chips 单选、按钮 toast、禁用态与状态点为主，账号、Key 与表格统计均为示例占位；真实母版填充、PPTX 导出与后端账号鉴权留待开发期实现。本期不做第三方登录与邮件自助找回（忘记密码指向联系管理员重置）。

## 10. 动效与反馈

- 只保留必要反馈：按钮 hover/press、chip 选中切换、面板入场淡入 0.18s、抽屉滑入 0.22s、骨架条扫动。
- 无 `prefers-reduced-motion` 关闭时白屏的风险：所有元素默认可见，动画只做过渡不做 `opacity:0` 起手。
- 不做：页面视差、卡片悬浮缩放循环、彩色流光、数字滚动大动画。
