# UI 设计美感与设计方法论

> 本文件是本专家的"设计功力"基线，**载体无关**（妙搭网页、原型、规范文档都适用）。`AGENTS.md` 的「UI 设计师专属交付优先级」与「Design System Flow」引用本文件。无障碍数值阈值以 `skills/ui-delivery-standard/references/accessibility-wcag.md` 为准。
>
> 美感不是玄学，而是可拆解、可复用、可讲清"为什么"的一组规则。每个设计决策都应能追溯到：用户目标 / 可用性 / 品牌调性 / 无障碍 中的至少一条。

## 1. 视觉层次（先看什么、后看什么）

- 用**尺寸、字重、颜色、间距、位置**五种手段共同建立层次，不靠单一手段。
- 每屏一个主视觉焦点（核心数据或 primary action），次级信息主动弱化。
- 字号阶梯用模块化比例：1.2（Minor Third）到 1.333（Perfect Fourth）之间取一档，全局统一。

## 2. 格式塔原则（元素如何被感知成组）

| 原则 | 落地做法 |
|---|---|
| 亲密性 Proximity | 相关元素靠拢，用**间距**而非分割线分组 |
| 相似性 Similarity | 同类元素同款式；不同功能给不同视觉 |
| 连续性 / 对齐 | 元素沿统一轴线对齐，减少视觉噪声 |
| 闭合 Closure | 用卡片、留白暗示边界，不必处处描边 |
| 图底关系 | 主体与背景对比明确；弹层用遮罩拉开层级 |

## 3. 色彩方法论

- **60-30-10**：主色约 60%、辅助色约 30%、强调色约 10%。
- 色板结构：品牌主色 + 中性灰阶（9~11 级）+ 语义色（success / warning / error / info）。
- 用 HSL 调明度/饱和度构建色阶；状态变化用同色相提亮或压暗 4~8%（hover / active）。
- **不靠颜色单独传达信息**（同时配图标或文字，SC 1.4.1）。
- 对比度阈值：正文 4.5:1、大字/图形对象 3:1（详见 accessibility-wcag.md）。

## 4. 字体排印（Typography）

- type scale 显式化，例如 12 / 14 / 16 / 20 / 24 / 32 / 40；正文 ≥14px，移动端 ≥16px。
- 行高：正文 1.5~1.75，标题 1.2~1.35。
- 字重建立层级（Regular / Medium / Semibold），全局不超过 3 种字重。
- 中英文混排：西文用专用字族，标点避免行首孤字；数字可用等宽以对齐。
- 每行长度：西文 45~75 字符、中文约 20~40 字最易读。

## 5. 间距与节奏（8px Grid）

- 统一 4 / 8px 基准的间距阶梯：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64。
- 组件内边距 < 组件间距 < 区块间距，形成三级节奏；层级越高留白越大。
- 相关元素小间距、不同区块大间距（呼应亲密性）。

## 6. 布局与网格

- 栅格：桌面 12 列 / 平板 8 列 / 移动 4 列；gutter 与 margin 显式定义。
- 视觉动线：内容密集页用 F 型，营销/落地页用 Z 型。
- 关键信息与主 CTA 落在视觉热区，不埋在过深的折叠线之下。

## 7. 一致性与设计系统

- 圆角、阴影、描边、图标风格**全局统一**，出自一套 token，不即兴。
- 阴影表达 elevation 层级，不滥用；同层级用同一阴影。
- 组件状态矩阵完整：default / hover / active / focus / disabled / error / loading / empty。

## 8. 留白与呼吸感

- 留白是主动的设计元素，不是"没排满"；它提升可读性与质感。
- 首屏敢于留白以突出核心；密集数据界面用留白分组来降噪。

## 9. 动效美学

- **有目的**：只做反馈、引导、连续性的动效，不炫技。
- 时长：微交互 150~300ms、转场 300~500ms；缓动入用 ease-out、出用 ease-in。
- 尊重 `prefers-reduced-motion`；动效不能是理解内容的唯一途径。

## 10. 设计要求方法论（需求 → 设计的转化）

- 动手前先问清五件事：**目标用户、使用场景/设备、核心任务、品牌调性、硬约束**（无障碍/性能/合规）。
- 需求不明确时，先给一套明确的**设计假设**（写进 `design.md` 的"设计前提"），据此设计，而不是模糊两可地铺开。
- 先定**风格关键词/情绪板**（如"专业克制""年轻活力""科技冷感"），再把它翻译成具体的色彩、字体、圆角、阴影、动效参数。
- 评审时每个决策都能讲清"为什么这样"，并能给出被否决的备选与取舍理由。
