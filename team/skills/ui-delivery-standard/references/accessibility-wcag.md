# 无障碍阈值（WCAG 2.2 AA，可核验口径）

本文件是 HS4 的数值真相源。阈值取自 W3C WCAG 2.2 与主流平台规范；**不要一刀切写"对比度≥4.5:1"**——对比度分三档，混用会误判。

## 1. 对比度（WCAG 2.2 SC 1.4.3 文本 / SC 1.4.11 非文本）

| 对象 | 最低比值 | 说明 |
|---|---|---|
| 正文文本 | **4.5:1** | 常规字号正文与背景 |
| 大字文本 | **3:1** | 大字 = ≥18pt(≈24px) 常规，或 ≥14pt(≈18.66px) 粗体 |
| UI 组件 / 图形对象边界 | **3:1** | 按钮/输入框边框、图标、图表关键形状、焦点指示 与相邻色（SC 1.4.11） |
| 纯装饰 / 禁用态 / logo | 不作要求 | — |

判定：用色值算对比度（在线可查或 `(L1+0.05)/(L2+0.05)`，L 为相对亮度）。低于阈值即不合格，进例外清单需说明理由。

## 2. 字号与缩放

- 正文最小 **≥14px（移动端建议 ≥16px）**；`font-size` 用 px/rem，**不与 pt 混用**（pt 属打印单位，屏幕产物统一 px/rem，对应 selfcheck A11Y-03）。
- 支持 **200%** 内容缩放，布局规则不得丢失或裁切内容（SC 1.4.4）。
- 类型阶梯（type scale）在 design.md 显式列出，正文/标题/标签层级分明。

## 3. 触控目标尺寸

| 规范 | 最小尺寸 | 级别 |
|---|---|---|
| WCAG 2.2 SC 2.5.8 Target Size (Minimum) | **24×24 CSS px**（含间距豁免） | AA |
| WCAG 2.1 SC 2.5.5 Target Size (Enhanced) | **44×44 CSS px** | AAA |
| Apple Human Interface Guidelines | **44×44 pt** | 平台建议 |
| Material Design | **48×48 dp** | 平台建议 |

移动端交付默认对齐 **44×44 pt / 48×48 dp**（更稳），至少满足 AA 的 24×24 CSS px。

## 4. 焦点、键盘与反馈

- 所有可交互元素可**键盘可达**，`Tab` 顺序合理，**焦点可见**（焦点环对比≥3:1，SC 2.4.7/2.4.11）。
- 浮层/弹窗关闭后焦点**回到触发元素**。
- 表单：必填有标识，错误有**文字说明+aria-invalid**，验证码/异步操作有加载与结果反馈（不只靠颜色，SC 1.4.1 不靠颜色单独传达信息）。
- 触控不依赖悬停/精确点选；自定义手势有可发现的等价操作。

## 5. 结构与语义

- `<html lang>` 必填；图片 `alt`（装饰图 `alt=""`）；标题层级 `h1→h6` 不跳级；地标 `header/nav/main/footer`。
- 动效仅用于解释状态/反馈；尊重 `prefers-reduced-motion`（SC 2.3.3）。

## 6. 规范文档自身可读

- design.md / 交付说明本身也要达可读性：对比达标、层级清晰、表格不塌、代码块可复制。规范文档不可读，等于没交付。
