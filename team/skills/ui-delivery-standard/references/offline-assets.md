# 离线可用性与资源本地化（HS3）

问题列表第 5 条落地：**zip 导出必须包含完整本地资源。**

## 硬规则

1. **资源随包**：图片、字体、CSS、JS、mock 数据全部放进交付目录并**相对路径**引用（`./assets/x.png`），不引用平台 CDN 绝对路径、不引用 `https://…` 外链。`selfcheck.py` OFF-01/02/03 会拦截。
2. **图片本地化或降级**：
   - 首选把图片下载/生成到 `assets/` 并相对引用；
   - 确无法本地化时，提供**降级方案**：占位底色 + `alt` 文案 + 明确标注"该图依赖在线资源，离线不可见"。
3. **字体**：优先系统字体栈（`-apple-system, PingFang SC, Microsoft YaHei, sans-serif`）避免外链 web font；必须用自定义字体时随包 `@font-face` 本地文件。
4. **宿主协议依赖**：任何依赖妙搭/飞书宿主能力的功能（如调宿主 API、鉴权、消息回调），在离线/导出场景**不可见或降级**，必须在交付说明显式标注"离线不可用"，不能让用户以为是 bug。

## 检查方法

```bash
# 1) 静态：扫外链资源
python3 scripts/selfcheck.py <交付目录>          # 看 OFF-01/02/03
```

## 交付目录建议结构

```
delivery/
├── index.html          # 入口
├── pages/              # 其余页面
├── assets/             # 图片、字体、图标（全部本地）
│   ├── img/
│   └── fonts/
├── design.md           # 设计规范（HS5 必交付）
└── selfcheck.json      # 自测结果留档
```

zip 前再跑一次 selfcheck 扫描整个目录；外链资源检查通过，才算资源完整。
